# Как выложить «Познай себя» и открыть в Telegram

Готовый сайт лежит в папке `docs` (один файл `index.html`). Ему не нужен сервер: подойдёт любой хостинг статических страниц с адресом на `https://`.

Что работает в этой версии: все разделы, расчёты Бацзы и Матрицы, карта. Проводник задаёт вопросы из заготовленного набора, без ИИ. Ответы человека хранятся только в его браузере (или внутри Telegram на его устройстве) и никуда не отправляются.

## Шаг 1. Выложить сайт

### Вариант А: Netlify, без командной строки

1. Зарегистрируйся на https://app.netlify.com.
2. Открой https://app.netlify.com/drop и перетащи в окно папку `docs` целиком.
3. Через несколько секунд появится адрес вида `https://случайное-имя.netlify.app`. Имя можно поменять в настройках сайта (Site configuration → Change site name).

Чтобы обновить сайт, открой его в Netlify, раздел Deploys, и перетащи туда новую папку `docs`.

### Вариант Б: GitHub Pages

1. Создай на https://github.com новый публичный репозиторий.
2. Отправь в него проект командой `git push` (репозиторий уже подключён как `origin`).
3. В репозитории открой Settings → Pages, в поле Branch выбери `main` и папку `/docs`, нажми Save.
4. Через минуту сайт откроется по адресу `https://твой-логин.github.io/имя-репозитория/`.

Проверь адрес в обычном браузере на телефоне, прежде чем идти дальше.

## Шаг 2. Сделать Telegram Mini App

1. В Telegram открой бота **@BotFather** и отправь `/newbot`. Он спросит название (например, «Познай себя») и имя пользователя бота, которое должно заканчиваться на `bot`.
2. Отправь `/setmenubutton`, выбери своего бота, пришли адрес сайта из шага 1, затем подпись кнопки, например «Открыть».
3. Открой чат со своим ботом. Слева от поля ввода появится кнопка: по ней приложение открывается прямо в Telegram.

Чтобы получить прямую ссылку для пересылки, отправь BotFather `/newapp`, выбери бота, задай название, описание, картинку 640×360 и адрес сайта. В ответ придёт ссылка вида `https://t.me/имя_бота/название`. Её можно отправлять кому угодно.

Внутри Telegram страница сама разворачивается на весь экран и подстраивается под светлую или тёмную тему.

## Как обновлять

Все правки делаются в `index.html` в корне проекта. После них выполни в папке проекта:

```bash
node build.js
```

Команда пересоберёт `docs/index.html`. Затем загрузи его на хостинг заново. Адрес не меняется, и бота трогать не нужно.

## Что стоит знать заранее

- **Ответы привязаны к устройству.** Если человек откроет приложение на другом телефоне или очистит данные, карта начнётся с нуля. Перенос между устройствами потребует сервера или хранилища Telegram.
- **Живой ИИ-проводник.** Чтобы он работал для всех, нужен небольшой сервер и платный ключ API: ты оплачиваешь ответы каждого пользователя. В файлах этого нет.
- **Telegram в России.** Скрипт Telegram подгружается с `telegram.org`. Если этот адрес у человека недоступен, сайт всё равно откроется, просто без подстройки темы.
- **Тексты про здоровье.** Внизу страницы есть оговорка, что это не диагностика и не замена специалисту. Для публичного приложения её лучше не убирать.
